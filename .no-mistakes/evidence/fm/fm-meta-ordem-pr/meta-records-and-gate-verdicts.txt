# Persisted task records after each writer, and the watcher's own gate verdict

The watcher (bin/fm-watch.sh:1997) runs a task's PR merge poll only while
fm_pr_poll_artifacts_valid accepts the task record. A refused record is what it
reports as 'check: rejected unauthenticated state checks' - the merge then goes
unnoticed. Each section below shows the record a writer actually persists, then
that same gate's verdict, on the base commit and on the fixed commit.

Paths are per-run temp fixtures; the field ORDER of each record is the point.
